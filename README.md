# Projeto RPG (V1)

Meu primeiro RPG de texto em Python, jogado inteiramente pelo
terminal. Foi construído a partir de 4 vídeos-tutoriais onde aprendi
os fundamentos da linguagem: if/else, dicionários, listas, variáveis,
input e laços for.

É um projeto propositalmente simples — mas foi aqui que a curva de
aprendizado realmente começou. Pra fazer tudo funcionar direito,
precisei sair do que os vídeos ensinavam e correr atrás de soluções
próprias pros erros que iam surgindo no caminho.

Esse projeto acabou virando a base para o [RPG Overworld 2](LINK),
uma versão bem mais completa e reescrita com Programação Orientada a
Objetos, banco de dados e um sistema de mundo muito mais profundo.

## Como rodar

Rode o jogo direto em um terminal (CMD, PowerShell, Git Bash).
**Evite abrir pelo console/output integrado do VS Code** — o jogo
pode não se comportar corretamente por lá.

## Regras do jogo

- A cada 3 lutas na floresta, um **CHEFE** aparecerá.
- Derrote **5 Chefes** para acordar o **Boss Final**.
- Usar um item durante a batalha **não** consome o turno — dá pra
  usar vários itens antes de atacar.
- Algumas magias têm custo elevado de propósito.
- Subir de nível recupera todo o seu HP e MP.
- Alguns inimigos praticamente obrigam o uso de itens para sobreviver.
- A dificuldade é elevada de propósito.

## Sobre o projeto

Não é um jogo polido, e não pretende ser — é um retrato de onde
comecei. Cada solução aqui dentro veio de tentativa, erro, e muita
pesquisa fora dos vídeos originais.
